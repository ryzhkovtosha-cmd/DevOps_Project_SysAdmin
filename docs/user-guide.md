# Руководство пользователя VPN

Инструкция для сотрудников компании. Рассчитана на человека без технической подготовки: каждый шаг описан целиком, после каждого есть проверка.

Займёт около получаса, из них ваших действий — минут десять. Остальное — ожидание ответа администратора.

---

## Зачем это нужно

Когда вы работаете из кафе, аэропорта или гостиницы, ваш интернет-трафик проходит через чужое оборудование. Владелец этой сети — а иногда и просто человек за соседним столиком — может видеть, на какие сайты вы заходите.

VPN решает это так: ваш компьютер устанавливает зашифрованный канал до сервера компании, и весь трафик идёт внутри него. Со стороны видно только поток непонятных данных в сторону одного адреса.

Что вы получаете:

- **Защиту в чужих сетях.** Открытый Wi-Fi перестаёт быть проблемой.
- **Доступ к внутренним ресурсам компании.** Они доступны только через VPN — снаружи их не видно.
- **Приватность от провайдера.** Даже имена сайтов он не увидит: они тоже передаются внутри канала.

Чего VPN **не** делает: не защищает от вирусов, не заменяет пароли и не делает вас анонимным на сайтах, куда вы входите под своей учётной записью.

---

## Как устроена выдача доступа

Коротко, чтобы шаги ниже были понятны:

1. На вашем компьютере создаётся **секретный ключ** — он никогда не покидает компьютер.
2. Вместе с ним создаётся **запрос** — его вы отправляете администратору.
3. Администратор возвращает **архив** с разрешением на подключение.
4. Вы соединяете архив со своим ключом и получаете файл для подключения.

Ваш секретный ключ не видит никто — ни администратор, ни сервер. Поэтому даже если переписку перехватят, подключиться от вашего имени не получится.

---

## Что понадобится

- Компьютер с Windows, macOS или Linux.
- Права администратора на этом компьютере — чтобы установить программу.
- Доступ к рабочей почте.

Если чего-то нет, напишите на **sysadmin@company.ru** — поможем.

---

## Шаг 1. Откройте терминал

Терминал — окно, куда вводятся команды. Все команды из этой инструкции можно копировать и вставлять целиком.

**macOS.** Нажмите `Cmd + Пробел`, наберите «Терминал» и нажмите Enter.

**Windows.** Сначала установите бесплатную программу Git for Windows со страницы [git-scm.com/download/win](https://git-scm.com/download/win) — при установке везде нажимайте «Next». Затем в меню «Пуск» найдите и откройте **Git Bash**. Дальше все команды вводятся в нём.

**Linux.** Нажмите `Ctrl + Alt + T`.

**Проверка.** Вставьте в окно команду и нажмите Enter:

```
openssl version
```

Должна появиться строка с номером версии, например `OpenSSL 3.0.2`. Если вместо этого написано «command not found» — напишите администратору.

---

## Шаг 2. Скачайте два небольших скрипта

Это программы, которые сделают всю техническую работу за вас. Вставьте в терминал целиком:

```
mkdir -p ~/vpn-setup && cd ~/vpn-setup
curl -fsSLO https://raw.githubusercontent.com/ryzhkovtosha-cmd/DevOps_Project_SysAdmin/main/scripts/client/gen-client-request.sh
curl -fsSLO https://raw.githubusercontent.com/ryzhkovtosha-cmd/DevOps_Project_SysAdmin/main/scripts/client/assemble-config.sh
chmod +x *.sh
ls
```

**Проверка.** Последняя команда должна показать два файла: `assemble-config.sh` и `gen-client-request.sh`.

---

## Шаг 3. Создайте ключ и запрос

Вместо `ivanov` подставьте свою фамилию **латиницей**, без пробелов:

```
./gen-client-request.sh ivanov
```

Скрипт создаст два файла в скрытой папке `.infra-vpn` вашей домашней папки:

| Файл | Что с ним делать |
|---|---|
| `ivanov.key` | **Никому не отправлять.** Это ваш секретный ключ |
| `ivanov.req` | Отправить администратору |

В конце скрипт напечатает **отпечаток** — длинную строку из букв и цифр после слов `SHA2-256(stdin)=`. Скопируйте её, она понадобится на следующем шаге.

Если у вас два устройства, например ноутбук и телефон, для второго создайте отдельный запрос с другим именем: `./gen-client-request.sh ivanov-phone`.

---

## Шаг 4. Отправьте запрос администратору

Напишите письмо на **sysadmin@company.ru** и приложите файл `ivanov.req`. Где он лежит:

- macOS и Linux — в папке `.infra-vpn` вашей домашней папки. В окне выбора файла нажмите `Cmd + Shift + .` (macOS) или `Ctrl + H` (Linux), чтобы увидеть скрытые папки;
- Windows — `C:\Users\ваше_имя\.infra-vpn\`.

В тексте письма **укажите отпечаток** из шага 3. Администратор сверит его с полученным файлом — так он убедится, что письмо не подменили по дороге.

Файл `ivanov.key` **не прикладывайте**.

---

## Шаг 5. Установите программу для подключения

Пока ждёте ответа, поставьте программу.

| Система | Программа | Откуда |
|---|---|---|
| macOS | Tunnelblick | [tunnelblick.net](https://tunnelblick.net) |
| Windows | OpenVPN Connect | [openvpn.net/client](https://openvpn.net/client/) |
| Linux | пакет openvpn | команда `sudo apt install openvpn` |
| iPhone, iPad | OpenVPN Connect | App Store |
| Android | OpenVPN Connect | Google Play |

---

## Шаг 6. Соберите файл для подключения

В ответ придёт архив `ivanov-bundle.tar.gz`. Сохраните его в папку `vpn-setup`, созданную на шаге 2, и выполните:

```
cd ~/vpn-setup
./assemble-config.sh ivanov-bundle.tar.gz
```

Скрипт соединит присланные файлы с вашим секретным ключом и создаст файл `ivanov.ovpn` в папке `.infra-vpn`.

**Проверка.** Скрипт завершится строкой «Готово» и путём к файлу. Если написано «Присланный сертификат не соответствует вашему ключу» — вы собираете архив не на том компьютере, где создавали запрос, либо архив прислан не тот. Напишите администратору.

---

## Шаг 7. Подключитесь

### macOS

1. Дважды щёлкните файл `ivanov.ovpn`. На вопрос, для кого установить, выберите **Only Me**.
2. Введите пароль от компьютера — он нужен, чтобы система разрешила изменить сетевые настройки.
3. Щёлкните значок Tunnelblick в строке меню вверху экрана, затем **VPN Details**, выберите подключение, вкладка **Settings**. Включите две галочки:
   - **Route all IPv4 traffic through the VPN**;
   - **Disable IPv6 unless VPN server is reached using IPv6** — без неё некоторые сайты увидят ваш настоящий адрес.
4. Нажмите **Connect**.

### Windows

1. Сначала добавьте в файл одну строку — она закрывает утечку имён сайтов мимо канала. В Git Bash:

```
echo "block-outside-dns" >> ~/.infra-vpn/ivanov.ovpn
```

2. Запустите OpenVPN Connect, выберите **Import Profile**, затем **File**, и укажите файл `C:\Users\ваше_имя\.infra-vpn\ivanov.ovpn`.
3. Нажмите переключатель подключения.

### Linux

```
sudo openvpn --config ~/.infra-vpn/ivanov.ovpn
```

Дождитесь строки `Initialization Sequence Completed`. Окно не закрывайте: при закрытии соединение разорвётся.

### Телефон

Перешлите себе файл, **созданный отдельно для телефона** (см. шаг 3), и откройте его в OpenVPN Connect. Файл для ноутбука на телефоне не используйте.

---

## Шаг 8. Проверьте, что всё работает

Откройте в браузере [yandex.ru/internet](https://yandex.ru/internet).

Показанный IP-адрес должен быть **111.88.249.0** — это адрес сервера компании. Если адрес другой, соединение не работает или трафик идёт мимо него: смотрите раздел «Если что-то не работает».

## Правила пользования

**Файл .ovpn равнозначен паролю.** Внутри лежит ваш секретный ключ. Тот, кто получит файл, войдёт во внутреннюю сеть от вашего имени. Не пересылайте его, не выкладывайте в общие папки и не храните в мессенджерах.

**Одно устройство — один файл.** Если подключиться с двух устройств одним файлом, второе подключение разорвёт первое.

**Доступ действует год.** За месяц до окончания администратор получит автоматическое напоминание и свяжется с вами. Продление — те же шаги 3–6.

**Об утере сообщайте сразу.** Потерян или украден ноутбук, телефон, есть подозрение, что файл попал к посторонним, — напишите на sysadmin@company.ru немедленно. Доступ будет отозван, и старый файл перестанет работать. Промедление здесь опаснее неловкости.

## Если что-то не работает

| Что происходит | Что делать |
|---|---|
| Подключение долго висит и не устанавливается | Сеть блокирует VPN — так бывает в гостиницах и гостевых сетях офисов. Переключитесь на мобильный интернет. Если там работает — напишите администратору |
| Подключено, но сайты не открываются | Напишите администратору: проблема на стороне сервера |
| Подключено, но адрес на yandex.ru/internet прежний | macOS: проверьте две галочки из шага 7. Остальные системы — напишите администратору |
| Ошибка «certificate has expired» | Срок доступа истёк. Повторите шаги 3–6 |
| Ошибка «TLS key negotiation failed» | Файл устарел после обновления сервера. Запросите новый архив |
| Скрипт пишет «command not found» | Проверьте, что вы в папке vpn-setup: команда `cd ~/vpn-setup` |
| Интернет стал медленнее | Весь трафик идёт через сервер в Москве. Для работы с внутренними ресурсами VPN нужен, для просмотра видео — нет, можно отключиться |

## Куда обращаться

**Почта: sysadmin@company.ru**

Чтобы помочь быстрее, приложите к письму:

1. Название и версию вашей системы.
2. Что именно происходит и что вы ожидали увидеть.
3. Журнал подключения:
   - macOS: Tunnelblick, VPN Details, вкладка Log — скопируйте текст;
   - Windows: в OpenVPN Connect меню, затем Log;
   - Linux: весь вывод команды из шага 7.
4. Ваш адрес без VPN — команда `curl -s ifconfig.me` в терминале.

**Никогда не прикладывайте** файлы `.ovpn` и `.key` — в них ваш секретный ключ. Журнала достаточно.
